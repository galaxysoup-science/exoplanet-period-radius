# exoplanet-period-radius
I used data from the NASA Exoplanet Archive to plot orbital period against planet radius for all known exoplanets with both values. I wrote the code in Python using pandas and matplotlib, and I used log scales so planets across a wide range of sizes and orbits are visible. I then colored each planet by the method used to discover it. I noticed that the transit method finds most of the small planets with short orbits, while methods like microlensing and imaging find planets with much longer orbits, which suggests each method is biased toward certain kinds of planets.
